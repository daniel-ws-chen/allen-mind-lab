# PBS 闖關島｜第八輪完整主路徑焦點測試（2026-10-31）

## 方法與限制
- 使用本機 v5.8 遊戲原始 HTML，加上與 PR #42 已提交之第七輪焦點管理邏輯相同的修正。
- Chromium + Playwright，透過 `page.set_content()` 測試。這是**本機等效程式測試**，不是公開／預覽部署網址。
- 每回合選擇劇本預設的較適切策略；不代表所有選項組合。
- 以 DOM 的 `document.activeElement.id` 判斷是否聚焦 `#screen`；未以實際螢幕閱讀器驗證播報。
