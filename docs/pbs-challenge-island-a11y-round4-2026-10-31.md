# 第四輪｜無障礙程式修正紀錄（2026-10-31）

## 變更
- 原本 MutationObserver 監看整個 `#screen` 的 childList 變化，不論操作類型均執行 `sceneFocus()`，可能在展開線索時搶走焦點。
- 改為：只有當焦點回到 `body`，或目前焦點元素已經從 DOM 移除時，才將焦點帶回遊戲主區。
- 主畫面的 `aria-live` 從 `polite` 改為 `off`，另設語意化的 `role="status"` 小型 live region，於階段狀態改變時宣告簡短訊息。
- 強化策略按鈕、下一步按鈕與線索按鈕的 `:focus-visible` 外框。
