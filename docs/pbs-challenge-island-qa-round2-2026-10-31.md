# PBS 闖關島｜第二輪程式驗收（2026-10-31）

測試目標：測試分支內 v5.8 遊戲之七島逐項回饋資料與執行穩定性。

## 測試方法
- 取自 v5.8 原始 HTML，使用系統 Chromium + Playwright 的 `page.set_content()` 測試。
- 對一般島各情境依序建立**獨立的初始狀態**，各選項單獨呼叫 `question()`、`choose()`。
- 檢查作答後狀態為 `reaction`、有 `.pbsReason` 解析區塊、無瀏覽器 JavaScript exception。
- 靜態列舉五場魔王戰的回合及選項；本輪不宣稱窮舉所有連續路徑。

## 無障礙觀察與限制
- 題目按鈕為語意化 `button`，額外線索使用 `aria` 展開狀態；仍須鍵盤操作實測及螢幕閱讀器實測。
- 本測試並未執行 axe-core、WCAG 2.2 AA 全面自動稽核或人工感知檢查，**不構成認證**。
- 逐項單回合測試不能證明任意多回合組合、結算或儲存邏輯皆正確。
