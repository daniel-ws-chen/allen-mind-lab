# PBS 闖關島｜第三輪端到端驗收（2026-10-31）

**測試對象**：v5.8 獨立遊戲 HTML（Playwright + Chromium、390×844 模擬視窗）
**部署狀態**：僅 GitHub 測試分支，不代表 Cloudflare／正式網站已部署。

## 實際執行結果
- 一般島 1–7：依序對每一回合選擇 `effect===1` 的預設較適切策略，均可完成該島並顯示 `phase="finish"`、`completed.has(n)===true`。
- 地圖解鎖：依序由 1 到 6（第七島索引為 6）；第七島完成後以 `completed` 七島全收集狀態開啟魔王島。本輪檢查一般島完成狀態，未再次執行魔王戰完整 UI。
- 一般島失敗：客廳島連續採取劇本中的高風險選項，可到 `crisis=3` 並顯示失敗結局（`phase="finish", fail=true`）。
- 基本鍵盤可達性：地圖畫面按 Tab，焦點會進入原生 `BUTTON` 闖關控制。
- 本輪未觀察到未處理 JavaScript `pageerror`。

## 驗收界線
- 本輪僅測試**單一成功策略路徑**及**一條失敗策略路徑**，非所有可能的連續決策組合。
- Tab 能聚焦並不代表鍵盤全流程或螢幕閱讀器符合 WCAG。
- 未跑 axe-core、實機 Android/iOS、螢幕閱讀器或實際部署預覽網址。
- 遊戲計分與劇本回饋不構成 PBS 專業效度或介入效果證據。
