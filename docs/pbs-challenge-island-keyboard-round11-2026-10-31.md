# 第十一輪｜魔王島失敗與本場重試鍵盤驗收（2026-10-31）

## 方法及限制
- 使用本地 v5.8 原始 HTML，套用與 PR #42 相同的焦點轉換修正邏輯，以 Chromium + Playwright 的 `set_content` 執行測試（390 × 844）。
- **並非直接從 GitHub 分支取得逐位元相同的 HTML，也不是已部署預覽網址**。
- 測試先以程式設定七島已完成，以便開啟魔王入口；其後透過頁面 DOM 按鈕聚焦 + 鍵盤 Enter 操作。按鈕定位使用選擇器，不是完整自然 Tab / Shift+Tab 巡覽。

## 具體結果
1. 鍵盤 Enter 啟動「AML 最終挑戰島」與「開始魔王戰」：進入 `bossQuestion`。
2. 第一戰三回合，以較適切策略依序完成並進入 `bossIntermission`，通過檢查點並進入第二戰（`bossGame.round===1`）。
3. 在第二戰連續選擇較高風險選項，風險值到 3，進入 `bossEnd` 失敗畫面。
4. 失敗畫面提供「從本場重新挑戰」按鈕。
5. 使用 Enter 啟動該按鈕後回到 `bossQuestion`，`round=1`、`turn=0`、`risk=0`，焦點為 `#screen`，**沒有退回第一戰**。
6. 本次未發現未處理 JavaScript 頁面例外。

## 結論
通過指定的「第一戰成功 → 第二戰失敗 → 第二戰檢查點重試」鍵盤啟動測試；PR #42 保持 Draft，不能據此認定全遊戲或無障礙 AA 驗收完成。
