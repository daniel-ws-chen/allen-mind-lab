3-1｜太陽的位置和四季有關嗎？

一句話記住：一年中日出日落時間、方位和中午太陽高度，都會隨季節呈現規律變化。
  1. 一天之中：太陽高度通常先變大，再變小，中午附近較高。
  2. 夏季：臺灣通常晝長夜短，中午太陽高度較高。
  3. 冬季：通常晝短夜長，中午太陽高度較低。
  4. 科學方法：可用長期觀察紀錄或天文軟體比較不同日期的太陽位置。
📊
資料判讀｜四季代表日

不必死背每個數字，先抓「夏季較長、冬季較短」的規律。

季節白天長短中午太陽高度
夏季較長較高
冬季較短較低

3-2｜太陽系有哪些成員？

一句話記住：太陽是太陽系唯一的恆星，八大行星包含地球，都環繞太陽運行。
  1. 太陽：自己會發出光和熱，是恆星。
  2. 八大行星：水星、金星、地球、火星、木星、土星、天王星、海王星。
  3. 距離與感受：太陽比其他恆星離地球近得多，所以我們能明顯感受到它的光和熱。
  4. 生命：地球上的生命高度依賴太陽提供的能量。
🪐
模型判讀｜太陽系不是「大小照順序排」

行星順序是依照與太陽的距離，不是依照行星大小。

水星金星地球火星木星土星天王星海王星

3-3｜四季的星空有什麼不一樣？

一句話記住：不同季節的代表星空會不同；星座盤與天文軟體可以協助辨認星座和方向。
  1. 星座：人們把天空某區域的星星用假想線連成圖案並命名，方便辨認。
  2. 四季星空：同一時間觀察，不同季節可看到不同的代表星座。
  3. 北極星：可利用北斗七星或仙后座等星座協助尋找北極星。
  4. 距離：恆星彼此距離非常遙遠，常使用「光年」表示。
🧭
觀星策略｜先找方向，再找星座

使用星座盤時，要配合日期、時間與方位；不能把星座盤當成固定不變的一張圖。

為什麼四季星空會不同？

地球在一年中環繞太陽運行，因此夜晚朝向宇宙的方向會逐漸改變，所以不同季節可見的代表星空也會不同。
