1-1｜認識多位小數

一句話記住：小數點右邊依序是十分位、百分位、千分位。
個位小數點十分位百分位千分位
3.407

3.407 = 3 個一、4 個 0.1、0 個 0.01、7 個 0.001。

常見錯誤：看到 3.407，不可以把 407 當成「四百零七」直接比較；要看每個數字所在的位值。

1-2｜小數的大小比較

比較順序：整數部分 → 十分位 → 百分位 → 千分位，找到第一個不同的位數就能判斷。

例題｜3.48 和 3.507，哪個比較大？

整數部分都是 3；十分位比較：4 < 5，所以 3.48 < 3.507。

不用因為 507 看起來比較長才判斷，而是因為十分位先出現差異。

補 0 不改變數值：3.48 = 3.480，所以也可以把位數補齊後比較。

1-3｜多位小數的加減

直式計算真正要對齊的是位值，所以小數點自然會上下對齊。

加法

  3.480
+ 1.725
-------
  5.205

減法

  6.000
- 2.375
-------
  3.625
檢查方法：先估算。例如 3.48 + 1.725 大約是 3.5 + 1.7 = 5.2，因此 5.205 看起來合理。

1-4｜小數取概數

要取到哪一位，就看右邊下一位。0–4 捨去，5–9 進 1。

例題｜4.768 取到百分位

百分位是 6；看右邊千分位是 8，所以 6 要進 1。

4.768 ≈ 4.77

例題｜12.343 取到十分位

十分位是 3；看右邊百分位是 4，所以不進位。

12.343 ≈ 12.3
