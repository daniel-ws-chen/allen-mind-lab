4-1｜人們如何適應不同地形創造所需？

一句話記住：土地利用不是隨便選；坡度、水源、交通與災害風險，都會影響人們怎麼使用土地。
  1. 地形形成：臺灣位於板塊交界附近，地形多樣，山地比例高。
  2. 河川與山林：河川提供水資源，山林具有水土保持、生態與資源價值。
  3. 平原、盆地：地勢較平坦，通常較適合聚落、交通與農業發展。
  4. 丘陵、台地：可依坡度、水源與土壤條件發展農業、聚落或其他用途。

判讀方法

看到某種土地利用時，先問：這裡的地形條件是什麼？人們的需求是什麼？是否帶來新的風險？

4-2｜沿海的利用為什麼呈現多元發展？

一句話記住：不同海岸形態、港灣條件、風浪與腹地，會形成不同的沿海利用方式。
  1. 港口與運輸：適合停泊、交通便利的海岸，可發展港口與物流。
  2. 漁業與養殖：沿海水域可提供漁業與養殖資源，但也須留意水質與生態承載。
  3. 觀光與保育：特殊海岸地形可能兼具觀光、教育與保育價值。
  4. 能源利用：部分沿海地區具有風力等能源開發條件，也需要評估景觀與生態影響。

多元，不等於什麼都能放

同一片海岸可能同時有漁業、觀光、保育與能源需求，因此常需要比較不同使用方式的利益與影響。

4-3｜土地開發與環境保護該如何抉擇？

一句話記住：永續不是「完全不開發」，而是避免只看眼前利益，忽略環境承載與長期風險。
  1. 山坡地開發：若缺乏整體規畫，強降雨或地震時可能增加水土流失、山崩與土石流風險。
  2. 地下水：若為農業或養殖過度抽取地下水，可能造成地層下陷。
  3. 河川與海岸：污染、過度捕撈、工程開發都可能改變生態與生活環境。
  4. 永續做法：低衝擊耕作、保護區、總量管理、環境監測與民眾參與，都是可能的策略。

抉擇題怎麼想？

不要只問「要不要開發」，而要比較：誰得到好處？誰承擔風險？短期與長期影響是什麼？有沒有更低衝擊的替代方案？
