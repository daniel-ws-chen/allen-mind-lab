選主題｜把「臺灣」縮小成可研究的問題

一句話記住：好主題要明確、有資料可找，而且能在有限篇幅內說清楚。
  1. 太大：「臺灣的歷史」範圍太廣。
  2. 較好：「開港通商後北部城市為何發展較快？」有時間、地點與問題。
  3. 可延伸：「某種海岸利用如何影響居民與環境？」可以蒐集多種證據。

選題公式

地點／時間＋主題＋想回答的問題，通常比只寫一個名詞更容易研究。

找資料｜來源不只要「有答案」，還要可信

檢查四件事：誰發布？什麼時候？根據什麼？能不能和其他來源互相驗證？
  1. 優先：政府、博物館、學校、研究機構等可追溯來源。
  2. 注意日期：地理、人口、政策等資訊可能隨時間改變。
  3. 區分事實與意見：「港口貨運量增加」和「這是最好的港口」不是同一種敘述。
  4. 交叉查證：重要結論最好不要只靠一個來源。

整理小書｜不是把搜尋結果貼在一起

小書要有邏輯：問題 → 背景 → 證據 → 解釋 → 結論／反思。

範例架構｜「一條河如何改變一座城？」

① 河川位置與特色 → ② 人們如何利用 → ③ 帶來哪些發展 → ④ 出現哪些環境問題 → ⑤ 現在如何改善。

圖表也要會說話

不要只放地圖或照片。每張圖至少要能回答：「這張圖證明了什麼？」

合作檢核｜分工之後還要統整

真正的團隊合作是：共同決定方向、清楚分工、定期檢查、最後一起整合。
  1. 分工：有人找資料、有人整理圖表、有人負責文字與版面。
  2. 共同標準：來源格式、用詞與主題要一致。
  3. 交叉校對：每個人都要看過其他人的內容。
  4. 最後檢查：有沒有回答原本的研究問題？證據是否支持結論？
