② 數學深化：這個區間怎麼算出來？

先計算樣本比例 p̂ = x / n；再選擇區間估計方法。Wald方法直觀，但小樣本或比例接近0、1時，涵蓋率可能不理想；因此預設使用Wilson方法。

展開 Wilson 公式與逐步代入

Wilson 區間的中心與半寬：

中心 = (p̂ + z²/(2n)) / (1 + z²/n) 半寬 = z × √[p̂(1−p̂)/n + z²/(4n²)] / (1 + z²/n) 區間 = 中心 ± 半寬
展開 Wald 公式與標準誤
SE = √[p̂(1−p̂)/n] Wald CI = p̂ ± z × SE

雙側90%、95%、99%對應的標準常態臨界值約為1.645、1.960、2.576。Wilson與Wald的結果可能不同，並非計算錯誤。

③ 重複抽樣：95%到底代表什麼？

設定一個假設的真正母體支持率，讓電腦每次隨機抽取n人，建立一條信賴區間。觀察100次或1,000次之後，有多少條區間涵蓋真正支持率。

④ 回到里長的政策問題

20 / 30：95% Wilson區間約48.8%～80.8%，包含50%；21 / 30：約52.1%～83.3%，不包含50%。

在與雙側Wilson區間對應的5%分數檢定架構下，後者能拒絕「支持率為50%」的假設，但統計顯著不等於政策上一定重要。抽樣偏誤、未回覆、研究設計與實際決策風險仍需評估。
