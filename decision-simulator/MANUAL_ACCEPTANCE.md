## A. 鍵盤與焦點（必測）
- [ ] 由頁首開始，只使用 Tab / Shift+Tab 可抵達所有可操作元素，順序與閱讀邏輯一致。
- [ ] Enter / Space 可以使用三個領域的選項、繼續下一階段、閱讀回顧、重設或返回。
- [ ] 每次動態更換情境後，焦點落在當前階段標題；焦點外框可見且不被遮擋。
- [ ] 選項切換、重設後不留下無法操作的焦點；沒有鍵盤陷阱。
- [ ] 全程不使用滑鼠也能完成三階段探索。

## B. 螢幕閱讀器（必測）
- [ ] Windows/NVDA + Chrome 或 Edge：頁首標題、主要內容、操作群組、選項均可正確朗讀。
- [ ] Android/TalkBack + Chrome 或 iOS/VoiceOver + Safari：可操作全部選項及返回。
- [ ] 選擇後動態狀態通知不重複、不遺漏，焦點移動可理解。
- [ ] 決策探索紀錄顯示與隱藏狀態正確、可被朗讀。
- [ ] 在螢幕閱讀器的標題清單中，階層合理且不跳級。

## C. 放大與視覺（必測）
- [ ] 320px 窄畫面及 200% 放大，文字、按鈕未被截斷或互相遮擋。
- [ ] 等效 400% 放大測試完成（檢查內容重新排列與水平捲動）。
- [ ] 主要文字、按鈕、焦點外框及狀態資訊對比可讀。
- [ ] 文字放大、系統高對比與偏好減少動態效果時，資訊與操作不喪失。
- [ ] 專業情境中不只靠顏色傳遞含意。

## D. 內容與隱私（必測）
- [ ] PBS、管理學及身心障礙服務領域內容由實務專業者檢查，模擬後果避免被讀成必然發生。
- [ ] 釐清行為功能是推論而非診斷；安全事件依個別計畫及現場程序。
- [ ] 尊重服務對象權利、意願、個別差異，不以單一「正確」策略評分。
- [ ] 使用中不要求登入、真實姓名、個案資料，不保留非必要的個人資訊。

## E. 原網站回歸（必測）
- [ ] 確認無障礙標章仍存在且連往原認證的正確頁面。
- [ ] 互動探索艙與智能支援艙在桌面／手機都能使用，新增第三艙未影響原功能。
- [ ] 原有文章、進階自學室、工具、My AML 與重要頁面可正常開啟。
- [ ] 首頁、站內導覽、跳到主要內容、頁尾與網頁標題正常。
- [ ] 檢查網站是否符合當前標章維護及改版通報要求。
