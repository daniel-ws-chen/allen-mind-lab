## 最簡單的電腦端快速試玩（不需安裝程式）
- 前往固定版本的 [決策模擬艙 HTML 原始檔](https://github.com/daniel-ws-chen/allen-mind-lab/blob/f5075a76d41b3529c10919905068b1fcd5596b5c/decision-simulator/index.html)。
- 在 GitHub 檔案頁選擇 **Raw**，再以瀏覽器「另存新檔」存為 `aml-decision-simulator-rc.html`（檔案類型選 HTML，避免存成 `.txt`）。
- 雙擊該 HTML，在電腦 Chrome 或 Edge 中開啟；從三個領域選一個，完成三階段決策與反思。
- 已核查本候選檔案的 JavaScript/CSS 均嵌在同一 HTML，沒有外部 script、CSS 或圖檔依賴，**核心決策流程適合在本機離線試玩**。
- 注意：HTML 中「返回 AML 互動實驗室」等以 `/` 開頭的網站導覽連結，在 `file://` 開啟時不會正確導向正式網站；因此**此快速試玩僅能作模擬艙功能／鍵盤／文案檢視，不可用來判定全站導覽與網站部署合格**。
- 需要驗收互動實驗室三艙導覽或全部網站連結時，再使用下方固定 ZIP 搭配本機伺服器的方式；真實手機輔助科技需專用可存取預覽環境。
- 避免將這份尚未正式發布的候選 HTML 公開散布，也不要輸入真實個案資料。

- [ ] 由頁首開始，只使用 Tab / Shift+Tab 可抵達所有可操作元素，順序與閱讀邏輯一致。
