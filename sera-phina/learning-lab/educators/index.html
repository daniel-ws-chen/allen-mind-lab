老師／督導／臨床教師入口

Sera.Phina Learning Lab 的目的不是替學生提供更快的答案，而是讓學生的觀察、推論、選擇與修正歷程變得可見，讓回饋可以真正落在「怎麼想」。

教學核心：學生先形成自己的思考，再使用工具、AI 或教師回饋深化推理；回饋後，最重要的動作是回到原本的 reasoning trace 修改，而不是只留下老師或 AI 的答案。

Sera.Phina Learning Loop

共同的學習循環

不同 Lab 的任務不同，但都遵循同一個原則：先建立自己的 reasoning，再引入外部工具與回饋。

01Think學生先形成自己的觀察、問題或假設。
02Organize把事實、推論、證據與缺失資訊分開。
03Ask AI if neededAI 用於檢查與延伸，不取代第一層思考。
04Discuss老師、督導或臨床教師聚焦 reasoning process。
05Revise學生修改原本推理，留下思考如何改變的痕跡。

Teaching Use

可以放在課程的哪一個位置？

Sera.Phina 不需要整門課都圍繞工具。更適合把它放在學生需要「把思考外顯化」的節點。

1

課前

先完成初步 reasoning。老師進課堂前即可知道學生卡在哪裡，也避免一開始就被答案框住。

2

課中

用學生輸出做小組討論，比較不同推理路徑；老師可以追問「你為什麼這樣想？」而不是直接糾正。

3

課後

學生依回饋修改原本 reasoning trace，留下前後差異，作為形成性評量或反思紀錄。

Feedback Prompts

回饋時，可以先問這些問題

以下不是評分規準，而是幫助學生把推理說清楚的 prompting language。

釐清事實與推論

當學生把觀察直接變成結論時，可用這組問題。

你目前寫的內容中，哪些是個案實際說過或觀察到的資料？ 哪些是你的解讀？ 如果把解讀拿掉，原始資料本身是什麼？

檢查診斷假設

避免「有某症狀＝某診斷」的過早收斂。

哪些資料支持你目前的假設？ 哪些資料其實不符合？ 如果你的第一個假設是錯的，還有哪些合理的解釋？

找 Missing Information

讓學生知道下一步要找什麼，而不是急著找答案。

如果現在還不能下結論，最重要還缺哪三項資訊？ 這些資訊分別會改變哪一個判斷？ 哪一項應該優先取得？為什麼？

回到 Occupation

避免討論停在症狀與診斷。

這些症狀對這個人的日常生活真正造成了什麼影響？ 哪些 occupation、角色、routine 或 participation 被改變？ 這是個人的能力問題，還是環境也在限制參與？

檢查 Assessment / FOR 選擇

要求學生先說明臨床問題。

你選這個 assessment 是想回答什麼臨床問題？ 如果不知道診斷名稱，你還會選它嗎？ 這個 FOR / model 對目前哪一個 occupational problem 最有解釋力？

要求真正的 Revision

回饋完成後，最重要的是學生修改原本 reasoning。

討論前，你原本怎麼想？ 哪一個新資訊或回饋改變了你的想法？ 現在你會刪掉、保留或新增哪一個假設？為什麼？
AI in the Learning Loop

AI 可以做什麼，也不應該做什麼

Sera.Phina 不要求學生一定使用 AI；若使用，重點是讓 AI 成為第二層的 reflection partner。

可以鼓勵

請 AI 找缺失資訊、指出推理跳躍、提出反證、協助整理不同解釋、產生需要查證的問題。

需要避免

直接貼案例要求 AI「告訴我答案」、把 AI 產生的診斷或介入當成臨床事實、沒有查證就直接提交。

教師可以追問

「你在問 AI 前已經知道什麼？」「AI 哪一點讓你改變想法？」「哪一點你沒有接受？為什麼？」

隱私與倫理

避免輸入可識別真實個案身分的資訊。使用外部 AI 時，資料處理仍受該平台的隱私政策約束。

Formative Assessment

建議看「推理變化」，不只看最後答案

若作為形成性評量，可觀察學生是否能完成以下動作，而不必把每次練習都轉成分數。

可觀察的學習證據

  1. 能否把描述、推論與假設分開。
  2. 能否提出支持與反對自己假設的資料。
  3. 能否辨識 Missing Information 與下一步資訊需求。
  4. 能否從 diagnosis 回到 occupation、role、routine、environment。
  5. 能否說明 assessment / FOR / intervention 的選擇理由。
  6. 接受 AI 或教師回饋後，是否真的修改原本 reasoning。
Closing Principle

回饋的終點不是「老師告訴答案」。

真正重要的是學生能說明：「我原本怎麼想、什麼讓我改變、現在我怎麼想，以及下一步還需要知道什麼。」
